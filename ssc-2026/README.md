# SSC 2026 — CANSSI Postdoc Spotlight talk

Files for the 30-minute talk on Tuesday 2 June 2026.

## Files

| File | Purpose |
|---|---|
| `slides.tex` | Beamer source (Metropolis theme, 16:9). Compile with `latexmk -pdf slides.tex` or upload to Overleaf. |
| `figures.R` | Generates all explainer and simulation PNGs into `figures/`. Run once with `Rscript figures.R` from this folder. |
| `figures/` | Output of `figures.R` plus one hand-placed map (`nwmp_map.png`). |
| `simulations/` | Simulation scripts and CSV outputs (one level up, in the package root). |

## Running `figures.R`

```bash
cd ssc-2026
Rscript figures.R
```

**Required R packages** (beyond the `multichangepoints` package itself):
`ggplot2`, `dplyr`, `tidyr`, `readr`, `patchwork`

The script reads three simulation CSVs from `../simulations/output/`:
- `joint_sim_results.csv` — produced by `../simulations/joint_simulations.R`
- `localized_sim_results.csv` — produced by `../simulations/localized_simulations.R`
- `bounded_sim_results.csv`, `bounded_w_results.csv`, `bounded_nu_results.csv` — produced by `../simulations/bounded_simulations.R`

Run the simulation scripts first if the CSVs are missing or stale.

## Overleaf setup

- **Compiler**: pdfLaTeX (XeLaTeX/LuaLaTeX if you want Fira fonts)
- **Main document**: `slides.tex`
- Upload the whole `ssc-2026/` folder, including `figures/` and its subdirectories, after running `figures.R` and the wastewater vignette locally.
- Note: `slides.tex` references figures using their full relative paths including subdirectories (`figures/simulations/cad/...`, `figures/nwmp/...`).  After pulling from Overleaf, check that any locally renamed or moved files are reflected in the path updates.
