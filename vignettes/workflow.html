multichangepoints workflow

This vignette demonstrates the core workflow for sequential change-point detection with:

  • IID Gaussian data generating process (DGP)
  • simple-vs-simple test supermartingale (TSM)
  • Shiryaev-Roberts (S-R) detector

1. Specify a Gaussian model and TSM

# define a simple change model, including all pre-change and post-change parameters
model <- GaussianModel(
  mean_pre = 0,
  sd_pre = 1,
  mean_post = 1,
  sd_post = 1
)

# construct a tsm object from the model, it will receive data
tsm <- TSM(model)

2. Create an IID Gaussian DGP

# set up the data generating process for the data sequence, including the pre/post distributions and the change-point
dgp <- DGP(
  generator = default_gaussian_dgp,
  pre_params = list(mean = 0, sd = 1), # parameters pre-change
  post_params = list(mean = 1, sd = 1), # parameters post-change
  nu = 120, # change-point
  name = "iid-gaussian-change"
)

# generate data from the dgp
N <- 250
x <- generate_stream(dgp, N = N, K = 1)
head(x)
#> [1] -0.2698252 -0.9911324 -0.4595598 -0.8808831 -1.4012064  1.9237771

3. Build increments and run the S-R detector with ARL control

# increment sequence from data x
inc <- compute_increments(tsm, x, log = TRUE)

# instantiate a detector class with ARL control

  alpha = 0.05, # average run length without false alarm is only 20
  criterion = "ARL"
)
sr_2 <- ShiryaevRobertsDetector(
  alpha = 0.001, # average run length without false alarm is 1000
  criterion = "ARL"
)


# push increments through detector sr

  • stopping_time: first alarm time (or Inf)

Multivariate detection

Simple-vs-simple multivariate detection. Note that when the alternative is mis-specified, the helper TSM does not grow and the detector can be very inefficient.

  name = "mv-gauss-change"

Combining

The same x from above has K = 3 independent Gaussian streams with a sparse change: only stream 1 shifts from mean 0 to mean 1. We fit a marginal simple-vs-simple TSM for each stream using the true marginal parameters, then combine the resulting increment sequences three ways: product (assumes independence), average (valid under arbitrary dependence), and universal portfolio (valid under arbitrary dependence, adapts weights online).

# ---- marginal models, one per stream, from the MVN DGP parameters ----
mu_pre  <- dgp_mvn@pre_params$mu
mu_post <- dgp_mvn@post_params$mu
sd_pre  <- sqrt(diag(dgp_mvn@pre_params$Sigma))
sd_post <- sqrt(diag(dgp_mvn@post_params$Sigma))

marg_tsms <- lapply(seq_len(K), function(k) {
  TSM(GaussianModel(
    mean_pre  = mu_pre[k],
    sd_pre    = sd_pre[k],
    mean_post = mu_post[k],
    sd_post   = sd_post[k]
  ))
})

# marginal log-increments: N x K matrix (one column per stream)
marg_inc <- sapply(seq_len(K), function(k) {
  compute_increments(marg_tsms[[k]], x[, k], log = TRUE)
})

# ---- combine marginal increments ----
inc_avg <- combine_streams(AverageCombiner(),            marg_inc, log = TRUE)
inc_prd <- combine_streams(ProductCombiner(),            marg_inc, log = TRUE)
inc_up  <- combine_streams(UniversalPortfolioCombiner(), marg_inc, log = TRUE)

# ---- run the same detector on each combined sequence ----
sr_comb <- ShiryaevRobertsDetector(alpha = 0.001, criterion = "ARL")
det_avg <- run_detector(sr_comb, inc_avg, log = TRUE)
det_prd <- run_detector(sr_comb, inc_prd, log = TRUE)

AR(3) change-point detection

So far every example has used iid Gaussian data. Here we demonstrate that the same pipeline handles autoregressive observations. We use an AR(3) process with a shift in the long-run mean from 0 (pre-change) to 0.5 (post-change); the AR coefficients and innovation variance are held fixed across regimes so that only the level shifts.

1. Define model and simulate data

set.seed(42)
N_ar  <- 300   # total horizon
nu_ar <- 150   # change-point

# AR(3) coefficients: moderate persistence, clearly stationary
phi <- c(0.5, 0.2, 0.1)   # phi_1, phi_2, phi_3  (sum = 0.8 < 1)
sigma_ar <- 0.5

model_ar3 <- ARpModel(
  phi_pre   = phi, sigma_pre  = sigma_ar, mean_pre  = 0,
  phi_post  = phi, sigma_post = sigma_ar, mean_post = 0.5
)

# Simulate an AR(3) path with a change at nu_ar
# Using the intercept parameterisation internally stored in the object
intercept_pre  <- model_ar3@mean_pre  * (1 - sum(phi))
intercept_post <- model_ar3@mean_post * (1 - sum(phi))

x_ar <- numeric(N_ar)
x_ar[1:3] <- 0   # initialise at pre-change mean
for (t in 4:N_ar) {
  intercept <- if (t <= nu_ar) intercept_pre else intercept_post
  x_ar[t]   <- intercept +
    phi[1] * x_ar[t - 1] +
    phi[2] * x_ar[t - 2] +
    phi[3] * x_ar[t - 3] +
    rnorm(1, sd = sigma_ar)
}

2. Compute TSM increments and run the detector

tsm_ar3 <- TSM(model_ar3)

# compute_increments handles the history automatically via the generic loop
inc_ar3 <- compute_increments(tsm_ar3, x_ar, log = TRUE)

sr_ar3  <- ShiryaevRobertsDetector(alpha = 0.001, criterion = "ARL")
det_ar3 <- run_detector(sr_ar3, inc_ar3, log = TRUE)

cat("Stopping time:", det_ar3$stopping_time, "\n")
#> Stopping time: 283
cat("Change-point: ", nu_ar, "\n")
#> Change-point:  150
cat("Detection delay:", det_ar3$stopping_time - nu_ar, "weeks\n")
#> Detection delay: 133 weeks

Change-point localization

Combining K marginal evidence streams into a single S-R statistic identifies when a change occurred, but discards information about which streams changed. The LocalizedDetector applies the Bonferroni correction to K independent marginal S-R detectors: each stream runs at level α/K, so the union bound guarantees a global ARL ≥ 1/α and global PFA ≤ α while returning per-stream stopping times and statistics.

The tradeoff depends on the sparsity of the change. Under a uniform change (all K streams shift), the product-combined increment accumulates K independent post-change likelihood ratios per step, so the joint detector fires dramatically earlier. Under a sparse change (only one stream shifts), the picture reverses: the K−1 null-stream log-increments average −0.5 each, pulling the combined log-increment negative on average and making the product-combining detector unreliable or slow — while the localized detector simply watches stream 1’s marginal S-R and is unaffected by the null streams.

We compare both on K = 10 IID Gaussian streams (N(0,1) pre-change, N(1,1) post-change) with a change at ν = 100:

  • Sparse change: only stream 1 shifts; streams 2–10 are unchanged.
  • Uniform change: all 10 streams shift simultaneously.

Setup

K     <- 10
N     <- 500
nu    <- 100
alpha <- 0.001    # global nominal level — ARL >= 1 000

set.seed(20260501)

# Shared marginal model and TSM: N(0,1) -> N(1,1)
marg_model <- GaussianModel(mean_pre = 0, sd_pre = 1, mean_post = 1, sd_post = 1)
marg_tsm   <- TSM(marg_model)

# Sparse scenario: only stream 1 shifts at nu
x_sparse                  <- matrix(rnorm(N * K), nrow = N, ncol = K)
x_sparse[(nu + 1L):N, 1L] <- rnorm(N - nu, mean = 1)

# Uniform scenario: all K streams shift at nu
x_uniform                <- matrix(rnorm(N * K), nrow = N, ncol = K)
x_uniform[(nu + 1L):N, ] <- matrix(rnorm((N - nu) * K, mean = 1), nrow = N - nu, ncol = K)

# Marginal log-increments: N-by-K matrix (column k = stream k)
inc_sparse  <- sapply(seq_len(K), function(k)
  compute_increments(marg_tsm, x_sparse[,  k], log = TRUE))
inc_uniform <- sapply(seq_len(K), function(k)
  compute_increments(marg_tsm, x_uniform[, k], log = TRUE))

Running the detectors

# Joint S-R: one detector at global level alpha fed product-combined log-increments.
# Joint threshold = 1/alpha = 1 000.
sr_joint <- ShiryaevRobertsDetector(alpha = alpha, criterion = "ARL")

det_joint_sparse  <- run_detector(sr_joint,
                       combine_streams(ProductCombiner(), inc_sparse,  log = TRUE),
                       log = TRUE)
det_joint_uniform <- run_detector(sr_joint,
                       combine_streams(ProductCombiner(), inc_uniform, log = TRUE),
                       log = TRUE)

# Localized detector: K marginal S-R detectors, each at level alpha / K = 0.0001.
# Marginal threshold = K / alpha = 10 000.
ld <- LocalizedDetector(K = K, alpha = alpha, criterion = "ARL")

det_loc_sparse  <- run_detector(ld, inc_sparse,  log = TRUE)
det_loc_uniform <- run_detector(ld, inc_uniform, log = TRUE)

# Per-stream N-by-K statistic matrices and K-length stopping-time vectors
stat_loc_sparse  <- sapply(det_loc_sparse$stream_results,  function(r) r$statistic)
stat_loc_uniform <- sapply(det_loc_uniform$stream_results, function(r) r$statistic)
stop_loc_sparse  <- sapply(det_loc_sparse$stream_results,  function(r) r$stopping_time)
stop_loc_uniform <- sapply(det_loc_uniform$stream_results, function(r) r$stopping_time)

loc_thresh_log <- log(ld@detectors[[1L]]@threshold)   # log(K / alpha)

fmt_stop <- function(t, nu) {
  if (is.finite(t)) sprintf("t = %d (delay %d)", as.integer(t), as.integer(t - nu))

Under sparse change the K−1 null streams each contribute a log-increment with expected value −0.5 per step (the KL divergence with sign reversed under the wrong model). With K = 10 and only stream 1 changing, the combined log-increment averages 0.5 − 9×0.5 = −4 per step: the joint product S-R drifts downward and rarely reaches its threshold within the observation window. The localized detector is unaffected — stream 1’s marginal S-R accumulates 0.5 nats per step against a threshold of log(10 000) ≈ 9.2, alarming after roughly 10 post-change steps — while streams 2–10 remain flat, immediately identifying the source of the change.

The two scenarios reveal a fundamental tradeoff:

  • Sparse change — the joint product detector is harmed by the K−1 null streams: their increments average −0.5 nats/step each, pulling the combined log-statistic downward so that the threshold is rarely cleared within a finite horizon. The localized detector ignores this dilution — each marginal S-R receives only its own stream’s increments — and correctly fires on stream 1 within ∼10 steps while leaving streams 2–10 quiescent.

  • Uniform change — the product of K post-change increments grows K times faster in log-space, giving the joint detector an overwhelming speed advantage over the localized detector (which pays the K-fold Bonferroni threshold penalty without benefiting from signal aggregation). The localized detector compensates with diagnostic value: the per-stream alarm map immediately confirms that all K streams have changed.
